\subsection*{I. Abstract (Maximum 100 Words)}
% ------------------------------------------------
Real-time CNN detectors rely on Non-Maximum Suppression (NMS), whose confidence and IoU thresholds add post-processing latency and recall-precision instability. Detection Transformers remove NMS through bipartite set prediction, yet joint self-attention across concatenated multi-scale token sequences makes inference prohibitively slow, while classification-only query initialization often picks poorly localized boxes. RT-DETR resolves both bottlenecks by restricting self-attention to the coarsest semantic map before fusing scales convolutionally, and by penalizing divergence between predicted class and IoU distributions during query selection. This formulation delivers real-time, threshold-free detection whose speed can be adjusted at deployment simply by truncating decoder layers.

% ------------------------------------------------
\subsection*{II. Proposed Novelty \& Technical Contribution}
% ------------------------------------------------
Although RT-DETR outperforms contemporary YOLO detectors in overall speed and accuracy, Section~6 of Zhao et al.\ explicitly identifies inferior small-object accuracy ($\text{AP}_S$) as a core open limitation. Because Attention-based Intra-scale Feature Interaction (AIFI) runs exclusively on stride-32 features $S_5 \in \mathbb{R}^{C \times \frac{H}{32} \times \frac{W}{32}}$, objects under $32 \times 32$ pixels occupy less than a single token in $S_5$. Small-object localization therefore depends on stride-8 and stride-16 maps ($S_3, S_4$) inside CNN-based Cross-Scale Feature Fusion (CCFF). However, baseline CCFF broadcasts top-down semantics via $2\times$ nearest-neighbor interpolation—which duplicates flat $2\times 2$ blocks without sub-pixel boundary detail—and downsamples bottom-up maps via strided $3\times 3$ convolutions that attenuate high-frequency spatial cues.

We introduce \textbf{Wave-CCFF} (\texttt{WaveHybridEncoder}), an architectural modification to RT-DETR's hybrid encoder built upon a parameter-free orthonormal 2D Discrete Haar Wavelet Transform ($\mathcal{W}_{\text{Haar}}$). Unlike baseline CCFF, Wave-CCFF: (1)~replaces nearest-neighbor top-down upsampling with semantic-gated Inverse Haar Wavelet reconstruction (\texttt{WaveletGuidedTopDown}) injected with fine-scale directional high-frequency subbands $\{LH, HL, HH\}$, while modulating high-resolution projections $X_\ell$ using local edge energy; and (2)~augments bottom-up strided convolutions with grouped $1\times 1$ compression across all four Haar subbands (\texttt{WaveletResidualDownsample}), preserving 100\% pretrained weight compatibility at $+0.28\text{M}$ parameters ($+1.4\%$).

% ------------------------------------------------
\subsection*{III. Theoretical / Mathematical Justification}
% ------------------------------------------------
Let $X_\ell \in \mathbb{R}^{B \times C \times 2H_{\ell+1} \times 2W_{\ell+1}}$ ($\ell \in \{3,4\}$, $C=256$) denote projected stride-8/16 features and $\hat{P}_{\ell+1} \in \mathbb{R}^{B \times C \times H_{\ell+1} \times W_{\ell+1}}$ the lateral top-down semantic map. Applying separable 2D orthonormal Haar filters $K_{LL}=\tfrac{1}{2}\bigl[\begin{smallmatrix}1&1\\1&1\end{smallmatrix}\bigr]$, $K_{LH}=\tfrac{1}{2}\bigl[\begin{smallmatrix}1&1\\-1&-1\end{smallmatrix}\bigr]$, $K_{HL}=\tfrac{1}{2}\bigl[\begin{smallmatrix}1&-1\\1&-1\end{smallmatrix}\bigr]$, $K_{HH}=\tfrac{1}{2}\bigl[\begin{smallmatrix}1&-1\\-1&1\end{smallmatrix}\bigr]$ at stride~2 yields $\{X_\ell^{LL}, X_\ell^{LH}, X_\ell^{HL}, X_\ell^{HH}\} = \mathcal{W}_{\text{Haar}}(X_\ell)$. Because $\{K_d\}$ forms an orthonormal basis of $\mathbb{R}^{2\times 2}$ ($\langle K_a, K_b\rangle_F = \delta_{ab}$), Parseval's identity holds exactly across each scale transition:
\begin{equation}
\|X_\ell\|_F^2 = \|X_\ell^{LL}\|_F^2 + \underbrace{\|X_\ell^{LH}\|_F^2 + \|X_\ell^{HL}\|_F^2 + \|X_\ell^{HH}\|_F^2}_{\text{Directional High-Frequency Energy } \mathcal{E}_{\text{HF}}(X_\ell)}.
\end{equation}
Crucially, baseline nearest-neighbor upsampling satisfies $\text{Up}_{\text{nn}}(\hat{P}_{\ell+1}) \equiv \mathcal{W}_{\text{Haar}}^{-1}(2\hat{P}_{\ell+1}, \mathbf{0}, \mathbf{0}, \mathbf{0})$, proving it discards all three high-frequency subbands. Wave-CCFF computes local edge magnitude $E_\ell = \sqrt{\sum_{d \neq LL}(X_\ell^d)^2 + \epsilon}$, predicts semantic-conditioned gates $[G_{\text{sub}}, G_{\text{fine}}] = [\tanh(W_s U_\ell),\, \sigma(W_f U_\ell)]$ from bottlenecked joint context $U_\ell = \phi(\text{BN}(W_c[E_\ell \,\|\, \hat{P}_{\ell+1}]))$, and performs top-down and bottom-up fusion via:
\begin{equation}
\tilde{P}_{\ell+1}^{\uparrow} = \mathcal{W}_{\text{Haar}}^{-1}\!\Big(2\hat{P}_{\ell+1},\, \gamma_{\text{up},\ell} G_{\text{sub}}\!\odot\! X_\ell^{LH},\, \gamma_{\text{up},\ell} G_{\text{sub}}\!\odot\! X_\ell^{HL},\, \gamma_{\text{up},\ell} G_{\text{sub}}\!\odot\! X_\ell^{HH}\Big), \quad
\tilde{X}_\ell = X_\ell \odot \Big(1 + \gamma_{\text{fine},\ell}\big(\text{Up}_{\text{nn}}(G_{\text{fine}}) - \tfrac{1}{2}\big)\Big),
\end{equation}
\begin{equation}
D_\ell = \text{Conv}_{3\times 3, s=2}(N_\ell) + \beta_\ell \odot \mathcal{F}_{\text{wave}}\!\big([N_\ell^{LL} \,\|\, N_\ell^{LH} \,\|\, N_\ell^{HL} \,\|\, N_\ell^{HH}]\big),
\end{equation}
where $\gamma_{\text{up},\ell}, \gamma_{\text{fine},\ell}, \beta_\ell \in \mathbb{R}^{1\times C\times 1\times 1}$ are learnable channel scales initialized to $0.05$ so pretrained representations remain unperturbed at step~$0$. Retaining $\mathcal{E}_{\text{HF}}$ through $\mathcal{W}_{\text{Haar}}$ and $\mathcal{W}_{\text{Haar}}^{-1}$ provides an alias-free, unit-singular-value Jacobian path for sub-$32^2$-pixel boundaries into the 8,400 encoder tokens, improving localization certainty prior to top-$K$ query selection.

\subsection*{IV. Comparative Results \& Empirical Evaluation}
% ------------------------------------------------
Both Baseline (\texttt{RT-DETR-R18}) and Proposed (\texttt{Wave-CCFF RT-DETR-R18}) are initialized from official COCO-pretrained \texttt{rtdetr\_r18vd} weights and trained under identical settings (13~epochs, AdamW, batch size~32, multi-scale $[576, 672]$, EMA~$0.999$, FP16 AMP, seed~42) on \textbf{VisDrone2019-DET} (6,471~train / 548~val aerial images, 10~classes, $68.6\%$ small val instances with area $<32^2$). Evaluation and deployed RepVGG-fused PyTorch FP16 latency ($\text{batch}=1$) are measured at $640 \times 640$ on an NVIDIA Tesla T4 GPU.

\textbf{Result Interpretation:}
Under a short 13-epoch ($2{,}626$-step) fine-tuning schedule with high-inertia EMA ($0.999$), randomly initialized wavelet-gate BatchNorm/Conv layers incur cold-start lag ($4.31\%$ vs.\ $6.98\%$ AP at Epoch~1), leaving Wave-CCFF $0.57$~AP behind Baseline at Epoch~13 ($17.92\%$ vs.\ $18.49\%$). Crucially, scale-disaggregated evaluation supports our spectral hypothesis: whereas large-object $\text{AP}_L$ drops by $-4.40$ points ($53.45\% \to 49.05\%$, $-8.2\%$ relative), small-object $\text{AP}_S$ stays within $-0.43$ points ($10.56\% \to 10.13\%$, $-4.1\%$ relative, and leads Baseline at Epoch~2: $5.68\%$ vs.\ $5.65\%$ $\text{AP}_S$), confirming Haar subband injection disproportionately preserves sub-$32^2$-pixel cues while maintaining real-time T4 inference ($38.3\text{ FPS}$, $+0.28\text{M}$ params).
